🎮 Stone, Paper, Scissors Tournament Game

📌 Overview

This is a Python-based Stone, Paper, Scissors Tournament Game where a player competes against the computer. The user selects the number of points required to win the tournament, and the game continues until either the player or the computer reaches that target score.

The project demonstrates the use of Python fundamentals such as loops, conditional statements, input validation, random number generation, and score tracking.

---

✨ Features

- User-defined tournament target score.
- Input validation for tournament points and player choices.
- Random computer move generation.
- Round-by-round score tracking.
- Clear game status and tournament results.
- Beginner-friendly implementation using simple "if-elif-else" statements.

---

🎯 Game Rules

- Stone beats Scissors.
- Scissors beats Paper.
- Paper beats Stone.
- If both choices are the same, the round is a tie.
- The first player to reach the target score wins the tournament.
